# From demo to your first project

Trolley keeps one set of tasks across four planning views. There is no account
to create. Your desktop workspace is stored locally.

## Start with the demo

On first launch, choose **Explore the demo** to see the single synthetic
**Community garden launch** project, with eight example tasks. Try moving
a task, changing its priority, and switching
between Board, Timeline, Matrix, and List. Every view shows the same record.

Choose **Start empty** if you prefer to build your own workspace immediately.
The demo is an example, not a template automatically applied to your projects.

## Make a project

Open the project dashboard from the Trolley mark or **All projects**. Create
a project and give it a useful name. Open **Project setup** to adjust its
workflow, labels, terminology, local team members, and view defaults.

## Add a task

Use **New task** in any project view. Trolley puts it in the first active
workflow stage and opens its details. Give it a title, then add a description,
priority, dates, or labels as needed.

Add **Sub-tasks** for small, checkable steps. Checking these entries controls
the task's progress and completion. A **Parent task** relationship instead
links separate full task records, each with its own fields and progress.

Relationships, effort, and notes expand separately from everyday fields.
Estimated and actual hours are entered manually; Trolley has no running timer.

## Find your next piece of work

Project search matches titles, descriptions, and notes. **Filters** narrows
work by status, labels, priority, classification, assignee, or dates. Save a
preset for a combination you use often. Clear filters also clears the search.

Filters follow you between views and reset when you select a project.
Search all projects and tasks with **Ctrl+K** or **Cmd+K**.

## Useful shortcuts

| Shortcut | Action |
| --- | --- |
| Ctrl+K / Cmd+K | Search the workspace |
| / | Focus project search |
| 1 / 2 / 3 / 4 | Board / Timeline / Matrix / List |
| N | Focus Board's first quick-add field |
| Ctrl+Z / Cmd+Z | Undo a workspace change outside text fields |
| Ctrl+Shift+Z / Cmd+Shift+Z or Ctrl+Y / Cmd+Y | Redo outside text fields |
| Escape | Close the current search or panels |

Text fields keep their normal text undo. Pointer drag also has keyboard
controls: focus a move handle, press Space, use arrows, then Space to drop or
Escape to cancel.

Continue with [the four views](planning-views.md) or
[local data and backups](data-and-backups.md).

## Manage projects and appearance

On the project dashboard, Archive keeps a project recoverable. Delete is
available for active and archived projects and asks for confirmation. It
removes the project and all its tasks, columns, labels, local team, and saved
filters. Permanent deletion clears undo and redo history; use Archive if you may
need the project again.

The project header keeps New task, Undo, Redo, and Settings visible. In Settings,
Appearance offers Follow system, Light, or Dark theme and Comfortable or
Compact spacing. Appearance applies to every project.

Undo and Redo are disabled when their history is empty or a file action is
running. Opening another project preserves redo history; new edits clear it.
History applies across the workspace, not just the currently open project.
